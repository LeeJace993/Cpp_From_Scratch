> 🎮 **像素课堂入口:[cpp4scratch.html](cpp4scratch.html)** —— 在虚拟大学里修完一门 C++ 课:报到入学(摸底可选，可直接听第一课)→ 校园(教学楼/考场/实验室/教授办公室/图书馆/大礼堂)→ 教授介绍概念与示范 → 随堂练习、分步实验、讲评 → 章节考核(独立做,对 4/5 过,不过给补习清单)→ 误区笔记本自动生成 → 13 门全过毕业典礼。每小节各备一题「代码实战」（全 52 题）：亲手修复一段程序并通过结构核验；本章 4 段全部通过，或直接做五题考核答对 4 题，即解锁下一章。四节互动课随时可学。第一、二、七章(编译模型 / 类型系统 / 继承与多态)各有四节完整互动课时；第三~六章（表达式与求值 / 指针数组引用 / 宏与预处理 / struct 与 class）与第八~十三章（模板 / STL 容器与算法 / lambda 与可调用对象 / 资源管理与移动语义 / 并发编程 / 工程能力）各四节互动课，贯穿“卡片点选”类活动（变量追踪表、短路现场、求值事件排序、声明拆树、sizeof/strlen 表、指针追踪表、生命周期对照、生灭时间线、初始化次序表、三之法则判定、static 规则表、展开对照表、副作用现场、条件编译路径表、规范对照表、实例化对照表、位置判定表、推导判定表、命中判定表、容量追踪表、复杂度表、失效判定表、比较器判定表、捕获追踪表、落点判定表、存活判定表、接住方式判定表、泄漏判定表、计数追踪表、移动落点判定表、异常判定表、线程生命周期判定表、数据竞争判定表、线程安全判定表、异步行为判定表、断点判定表、现场判定表、断言线判定表、构建阶段判定表）——十三章全部为互动课。本地直接双击打开，或部署 GitHub Pages 在线玩。

第一章从源文件、编译和链接开始，介绍 `include`、翻译单元与声明/定义后，再分析链接错误；后续三课依次讲声明与 ODR、内部链接变量、命名空间。第二章从类型与 `sizeof` 讲起，三课依次讲 const 单层指针声明读法（从名字向左读）、auto 推导、四种 cast；考核与这四节课对应。第七章四课依次讲基类子对象与构造析构顺序、虚函数与覆盖、隐藏与静态绑定、切片与抽象类。第三章四课依次讲值与副作用、优先级与括号、短路求值、求值顺序与 C++17 三档。第四章四课依次讲声明阅读法（右左法则）、数组与 \0（sizeof 与 strlen 各管一头）、指针与 ++（贴身规则）、生命周期与返回（悬垂判定）。第五章四课依次讲展开与括号（宏是复印机）、副作用与 UB（参数出现几次求值几次）、条件编译（#ifdef 看名字 #if 看值）、现代替代与规范（constexpr 优先）；SQ(a++) 这类 UB 如实教“能编译不等于有答案”，ub.cpp 只看 GCC 警告不猜输出。第六章四课依次讲对象的生与死（图纸与房子、时间线）、初始化的规矩（列表、声明顺序与 explicit）、拷贝控制（默认拷贝与三之法则）、static 成员（一份存储全类共享）；shallow.cpp 的 double free 是 glibc 运行期检测，课程如实区分语言保证与工具行为。卡片点选类活动中点错的选项会得到当场讲评，全部点亮才能进入下一步。对象格子图和具体大小是特定实现的示例，不是标准保证的布局。

第一、二、三、四、七章顶部的阶段标题可点击，展开“本课目录”还能选择任意页。跳转后进入自由复习，未学完的课可以回到原正式学习位置；正式位置在退出或刷新后保留。自由复习不会替代课时完成条件，也不重复发放经验或直接提升掌握度。独立练习查看提示、重试或预看讲评后，正式作答记录为引导完成。旧版已通过或已开放的考核资格保留；错题来源按章节和课时共同定位。

实验是分步教学演示。课程内容经 g++ 真机核验（每章一套核验脚本）；核验脚本与工程文档保存在本地，不随本仓库发布。

每节课先填教学设计卡（学习目标 / 前置知识 / 核心示例 / 玩家操作 / 常见误区 / 独立练习），每道考核题标注教学出处。未定义行为的判断依据规则，不把某次实跑结果当作保证。

这套课程基于你自己的题库(学校 C++ 结业考试"喂饭"整理,约 360 题)重构,按斯坦福新生课的顺序组织:每一章先建立概念模型,再拆解该主题下的高频误区,然后**带你精做几道有特点的例题**,最后给出一批题库原题让你独立刷、交回来 review。

## 起点与终点

**起点画像**:你能读懂大部分 C++ 代码,有过刷题经验;但 struct/class 的对象模型、模板、宏的展开规则、头文件与链接机制,这些"为什么"层面的知识还没有连成系统。

**终点**:两个。

1. 考试层面:60 题、70% 及格。题库能力项地图给出的分布是——编程语言能力 65%(基础知识 17 题、标准库 9 题、面向对象 5 题、高性能 6 题、模板 2 题)、编程规范 20%(12 题)、软件测试 4 题、GDB 3 题、编译构建 2 题。也就是说,**第 02~12 章覆盖约 85% 的考题**。
2. 能力层面:拿到任何一道题,能说出"考的是哪条规则,错误选项错在哪",而不是凭眼熟选。

## 每章的固定动线

每一章都是同一个结构,你按同一条路线走:

1. **阶段 1~5 概念推进**:每个阶段只引入一个新概念,配最小示例与误区框;阶段末尾有一道即时自测,先自己答,再展开对答案。
2. **例题带做**:2~4 道从题库选出的、最能暴露误区的题,我逐步带做;所有输出题都经过实际编译验证,你也可以自己跑一遍核对。
3. **刷题任务卡**:一组题库原题(用题干关键词定位),按依赖顺序排列;你独立完成后,把"答案 + 一句话理由"交回来,我逐题 review——只反问,不改你的结论。
4. **章末自测清单**:能不看书回答这些问题,本章才算过。

## 两个约定

1. **题库答案仅供参考**。题库里不少题没有标注答案,标注过的也有错漏;凡是能上机验证的题,以实跑结果为准。这也是第 00 章的第一条学习方法。
2. **先答后看**。例题带做里每一步的反问,先自己给出答案再往下滚;跳着看例题 = 白做。
